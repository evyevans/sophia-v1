# Optional research routine specification

This is a template, not an installed or scheduled routine. First complete the one-time local demo and a Grok Bot acceptance run.

Before enabling, the owner must explicitly supply: routine owner, IANA timezone, schedule, local evidence path, collection responsibility, output directory, retention policy and host permissions. A 24/7 market does not imply the chosen review schedule is continuous surveillance.

Run the saved Sophia Research workflow on the supplied current snapshot. Do not create network access or substitute old/synthetic evidence. Preserve the evaluation time and all reason codes. Compare the status, gate codes and asset identity with the previous successful reviewed result; ignore timestamp/hash churn alone. Keep quiet when nothing meaningful changed. Notify in the owning conversation only on a meaningful evidence/risk change, a failed run or required user input, under that routine's explicit authorization.

No email sender, public posting, auto-rebalancer or execution permission is included. State comparison, scheduling and notifications are performed by the host and are untested here. A routine must not infer inherited permissions from this file.
